# AI Creative Studio

A next-generation creative tool for automated story creation, comic/manga production, and animation preparation using AI models.

## Features

- **Story Generation**: AI-powered story and script generation
- **Scene Segmentation**: Intelligent breakdown into visual scenes
- **Comic/Manga Creation**: Panel-based comic generation
- **Animation Preparation**: Storyboard to animation pipeline
- **Character Consistency**: Maintain character appearance across scenes

## Tech Stack

### Backend
- **FastAPI**: Python web framework
- **Celery**: Distributed task queue
- **PostgreSQL**: Primary database
- **Redis**: Caching and message broker
- **MinIO**: Object storage

### AI Services
- **Gemini API**: Advanced reasoning
- **Claude API**: Complex analysis
- **Replicate API**: Stable Diffusion, AnimateDiff
- **Together AI**: Open-source models (Llama/Mistral)

### Frontend
- **HTML5/CSS3/JavaScript**: Core web technologies
- **Manga Editor Desu**: Comic editing interface
- **TailwindCSS**: Styling framework
